# Upgrading to v0.12.0

The brand logos moved to their own repository, [A-Novel UI assets](https://github.com/a-novel-kit/ui-assets),
and ship as `@a-novel-kit/ui-images`. uikit no longer publishes `@a-novel-kit/uikit-images`.

## Do I need to act?

**Required if you depend on `@a-novel-kit/uikit-images`, or link its files from a README.** Its last
version, `0.11.0`, stays installable but receives no update.

## Install the images from their new package

The new package keeps every file path. Only the package name changes:

```bash
pnpm remove @a-novel-kit/uikit-images
pnpm add @a-novel-kit/ui-images
```

```diff
-import bannerUrl from "@a-novel-kit/uikit-images/files/banner/80h/studio-banner.png";
+import bannerUrl from "@a-novel-kit/ui-images/files/banner/80h/studio-banner.png";
```

The images release on their own version line, starting at `0.1.0`. A bundler fails on an unresolved
import, so a clean production build confirms the migration.

## Link README logos from the new repository

Logo URLs on uikit's `master` no longer resolve. Point them at the new repository's
`master`; the path inside the repository is unchanged:

```diff
-https://raw.githubusercontent.com/a-novel-kit/uikit/master/packages/images/files/banner/960h/kit-banner.png
+https://raw.githubusercontent.com/a-novel-kit/ui-assets/master/packages/images/files/banner/960h/kit-banner.png
```
