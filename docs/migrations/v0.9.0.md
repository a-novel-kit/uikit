# Upgrading to v0.9.0

UIKit names its own identifiers after A-Novel, which owns the code. Agora names the user-facing products
only, so the brand images keep their `agora-` file names.

| Before                           | After                           |
| -------------------------------- | ------------------------------- |
| `agoraTheme`                     | `aNovelTheme`                   |
| `agoraDesktop`, `agoraMobile`    | `aNovelDesktop`, `aNovelMobile` |
| `.agora-*` component classes     | `.a-novel-*`                    |
| `--agora-*` component properties | `--a-novel-*`                   |

## Do I need to act?

**Only if you import `agoraTheme`, select a viewport by ID, or style a component through its internal
class or custom property.** Rename the reference.

```diff
-import { agoraTheme } from "@a-novel-kit/uikit-storybook";
+import { aNovelTheme } from "@a-novel-kit/uikit-storybook";
```
