# Upgrading to v0.10.0

`@a-novel-kit/uikit-images` ships four logos, Agora, A-Novel, KIT, and Studio, each in dark and light
modes. Every logo shares one ladder of banner heights, and banner directories now name a height.

## Do I need to act?

**Required if you import an Agora banner.** Its directory moved from a width to a height. Icon paths
and file names are unchanged.

## Import banners by height

Banner widths follow each logo's aspect ratio, so only the height is common to every logo. Each new
Agora file stays within 0.5% of the width its old directory named.

| Before                                | After                                |
| ------------------------------------- | ------------------------------------ |
| `files/banner/320w/agora-banner.png`  | `files/banner/80h/agora-banner.png`  |
| `files/banner/640w/agora-banner.png`  | `files/banner/160h/agora-banner.png` |
| `files/banner/960w/agora-banner.png`  | `files/banner/240h/agora-banner.png` |
| `files/banner/1280w/agora-banner.png` | `files/banner/320h/agora-banner.png` |
| `files/banner/1920w/agora-banner.png` | `files/banner/480h/agora-banner.png` |
| `files/banner/2560w/agora-banner.png` | `files/banner/640h/agora-banner.png` |
| `files/banner/3840w/agora-banner.png` | `files/banner/960h/agora-banner.png` |

```diff
-import bannerUrl from "@a-novel-kit/uikit-images/files/banner/320w/agora-banner.png";
+import bannerUrl from "@a-novel-kit/uikit-images/files/banner/80h/agora-banner.png";
```

A `srcset` with width descriptors can keep its numbers. A bundler fails on a removed path, so a clean
production build confirms the migration.

## Notes

The other logos and the `-black`, `-light`, and `-light-white` variants are new files. The package
README lists the naming pattern.
