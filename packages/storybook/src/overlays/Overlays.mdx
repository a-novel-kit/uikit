# Disclosure and dialog

Accordion and Disclosure reveal content in the current flow. Popover, Dialog, and Tooltip render
above that flow and are documented in isolated subdocuments so their top layers stay inside each
example.

The header accepts caller-owned controls. Escape, backdrop clicks, and close controls ask the same
controller to close; a fixed Storybook controller can keep the preview open.

Long headings wrap beside header controls; supporting copy uses the full header width.

<ResponsiveStoryPair
  desktop={OverlayStories.LongHeadingDesktop}
  mobile={OverlayStories.LongHeadingMobile}
  meta={OverlayStories}
/>

```svelte
<Dialog controller={dialog} title="Details">
  {#snippet headerActions()}
    <IconButton label="Close dialog" variant="ghost" tone="neutral" size="sm" onclick={dialog.close}>
      <CloseIcon size="var(--icon-size-sm)" />
    </IconButton>
  {/snippet}
  <p>Additional information.</p>
</Dialog>
```

### Fullscreen

`presentation="fullscreen"` fills the viewport and lets the body scroll independently. The caller
owns navigation and content layout. The header and optional footer remain visible.
