# Disclosure and dialog

Accordion and Disclosure reveal content in the current flow. Popover, Dialog, and Tooltip render
above that flow and are documented in isolated subdocuments so their top layers stay inside each
example.

## Disclosure

<Canvas of={OverlayStories.Disclosure} />

The summary accepts text or an inline snippet, including an icon or badge. Keep interactive controls
in the revealed content so the summary remains one clear toggle target.

<Canvas of={OverlayStories.Accordion} />

```svelte
<Dialog controller={dialog} title="Details">
  {#snippet headerActions()}
    <IconButton label="Close dialog" variant="ghost" tone="neutral" size="sm" onclick={dialog.close}>
      <CloseIcon size="var(--icon-size-sm)" />
    </IconButton>
  {/snippet}
  <p>Additional information.</p>
</Dialog>
```

### Shared panel composition

`PanelHeader` supplies a compact heading, optional description and trailing controls. `ActionGroup`
owns responsive action spacing; `FormActions` adds form feedback and separation from inputs.
Compose the body with ordinary markup, `Stack`, and existing controls. These layout components own
no state or surface. A popover remains non-modal; use `Dialog` when background interaction must stop.

```svelte
<Stack gap="4">
  <PanelHeader title="Export a copy" description="The original stays in your workspace." />
  <ActionGroup align="end">
    <Button onclick={exportCopy}>Export</Button>
  </ActionGroup>
</Stack>
```

Import `PanelHeader`, `ActionGroup`, `Stack`, and `Button` from `@a-novel-kit/uikit`. Supply
`titleId` and `descriptionId` when a containing region needs to reference the header through ARIA.
`Dialog` supplies these associations automatically. Use the description for a short explanation;
put structured content in the body.
