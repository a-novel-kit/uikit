# A-Novel UI

A-Novel UI provides the Svelte components of A-Novel interfaces, and the tokens, fonts, brand images,
and icon canvas they build on.

## Packages

| Package                        | Purpose                                           |
| ------------------------------ | ------------------------------------------------- |
| `@a-novel-kit/uikit-tokens`    | Derived color, metric, motion, and type contracts |
| `@a-novel-kit/uikit-fonts`     | Self-hosted font faces and licensed WOFF2 assets  |
| `@a-novel-kit/uikit-images`    | Responsive banners and square application icons   |
| `@a-novel-kit/uikit`           | Styled Svelte components                          |
| `@a-novel-kit/uikit-icons`     | Shared canvas for custom icons                    |
| `@a-novel-kit/uikit-storybook` | Shared Storybook theme and configuration          |

## Setup

Load the font and token styles once at the application entry point.

```ts
import "@a-novel-kit/uikit-fonts/fonts.css";
import "@a-novel-kit/uikit-tokens/tokens.css";
```

## Translations

Components ship their built-in text, such as labels and placeholders, in English and French. They
follow the app's `@a-novel-kit/nodelib-i18n` provider: its language picks the messages and formats
dates. Without a provider, they render in English.

uikit adds its messages to the app's i18next instance under the `uikit` namespace and never replaces
the app's own. An app can reword a message or add a language uikit doesn't ship yet. It gives its
`uikit` namespace those keys. Any key it leaves out still comes from uikit, then from English.

## Storybook setup

Add the shared preset to a Svelte Storybook. It provides the A-Novel theme, dark preview, fonts,
tokens, documentation, and accessibility checks.

```ts
import type { StorybookConfig } from "@storybook/svelte-vite";

const config: StorybookConfig = {
  stories: ["../src/**/*.mdx", "../src/**/*.stories.@(js|ts|svelte)"],
  addons: ["@a-novel-kit/uikit-storybook"],
  framework: "@storybook/svelte-vite",
};

export default config;
```

Open the [component catalog](?path=/docs/components-catalog--documentation) to browse the available
groups.
