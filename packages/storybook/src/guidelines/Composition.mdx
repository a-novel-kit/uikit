# Composition

Build interfaces from small semantic parts. Components render UI; controllers own state and transitions. Applications own content and arrangement.

## Choose the smallest brick

| Need                                 | Use                                               |
| ------------------------------------ | ------------------------------------------------- |
| Place content with consistent rhythm | `Stack`, `Inline`, `Grid`, `Container`            |
| Name and describe a control          | `Field` or `Fieldset` around a control            |
| Perform an action                    | `Button` or `IconButton`                          |
| Navigate                             | `Link`, `NavList`, `Tabs`, or `Breadcrumbs`       |
| Reveal supporting content            | `Disclosure`, `Accordion`, `Popover`, or `Dialog` |

## Content hooks

Visible labels, descriptions, adornments, actions, and item renderers accept snippets where composition is useful. Keep plain text identifiers in the data model so keyboard search, accessible names, and application logic remain reliable.

Prefer children and named snippets over adding presentation-only options. Promote a repeated composition to a recipe before creating another primitive.

## Ownership

- Components own focus, keyboard behavior, state attributes, and token use.
- Controllers expose state and semantic methods through a typed contract. Instantiate the default factory outside the component, or supply a compatible implementation. Compose controllers by injecting child controllers or deriving views of shared state.
- Applications own routing, landmarks, page shells, data loading, validation rules, and domain workflows.
- Visual stories inject fixed-state controllers. Buttons still receive focus and content remains scrollable and selectable, but clicks cannot change the scenario. Live transitions are covered in controller and component tests.

```ts
import { type DialogController, createOpenController } from "@a-novel-kit/uikit";

// Application setup
const dialog = createOpenController();

// Visual-review fixture using the same contract
const preview: DialogController = {
  state: { open: true },
  open() {},
  close() {},
  toggle() {},
};
```

```svelte
<Dialog controller={dialog} title="Details">Additional information.</Dialog>
```
