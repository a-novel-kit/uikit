# Typography

Import `@a-novel-kit/uikit-fonts/fonts.css` once, then use the family and size tokens.

## Families

<div className="type-families">
  {families.map((family) => (
    <FamilySpecimen family={family} key={family.token} />
  ))}
</div>

## Scale

Use `md` for body text and move through adjacent steps to establish hierarchy.

<div className="type-scale" aria-label="Typography size scale">
  {sizes.map((size) => (
    <div key={size}>
      <code>{"--font-size-" + size}</code>
      <span style={{ fontSize: "var(--font-size-" + size + ")" }}>Agora interface</span>
    </div>
  ))}
</div>

## Weights

Use `--font-weight-regular` for body copy, `--font-weight-medium` for emphasis, and
`--font-weight-bold` for labels and headings.
