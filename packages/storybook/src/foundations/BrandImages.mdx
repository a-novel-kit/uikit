# Brand images

Import logo banners and square application icons from `@a-novel-kit/uikit-images`.

## Logos

Agora, A-Novel, KIT, and Studio each ship a banner and an icon in four variants. The variant suffix
ends every file name.

| Suffix         | Mode  | Background  |
| -------------- | ----- | ----------- |
| _(none)_       | Dark  | Transparent |
| `-black`       | Dark  | Black       |
| `-light`       | Light | Transparent |
| `-light-white` | Light | White       |

<div className="brand-image-grid brand-image-grid--logos">
  {logos.flatMap((logo) =>
    variants.map((variant, index) => (
      <figure className="brand-image-sample" key={logo.id + variant.suffix}>
        <div className={"brand-image-stage brand-logo-stage" + (variant.light ? " brand-image-stage--light" : "")}>
          <img alt="" src={logo.banners[index]} />
          <img alt="" src={logo.icons[index]} />
        </div>
        <figcaption>
          <strong>{variant.label}</strong>
          <code>{logo.id + "-*" + variant.suffix + ".png"}</code>
        </figcaption>
      </figure>
    ))
  )}
</div>

## Banner

Banners keep their logo's aspect ratio, and their directories name a height. Display a banner at a
fixed height and list the larger heights as density descriptors.

<figure className="brand-image-sample">
  <div className="brand-image-stage">
    <img
      alt="Agora"
      decoding="async"
      height="80"
      src={agoraBannerUrl}
      srcSet={`${banner160Url} 2x, ${banner240Url} 3x`}
      width="319"
    />
  </div>
  <figcaption>
    <strong>Fixed-height banner</strong>
    <code>files/banner/{"{height}"}h/agora-banner.png</code>
  </figcaption>
</figure>

## Icon

Choose the file whose intrinsic square size matches the platform surface. Keep the image square and
let the platform apply its own mask.

<div className="brand-image-grid">
  {iconSamples.map((sample) => (
    <figure className="brand-image-sample" key={sample.size}>
      <div className="brand-image-stage brand-image-stage--icon">
        <img
          alt=""
          height={sample.size}
          src={sample.url}
          style={{ "--brand-image-size": `${sample.size}px` }}
          width={sample.size}
        />
      </div>
      <figcaption>
        <strong>{sample.label}</strong>
        <code>{sample.size + "×" + sample.size}</code>
      </figcaption>
    </figure>
  ))}
</div>

The previews are decorative because their captions already identify each file. Product usage needs
meaningful alternative text unless adjacent content names the product.
