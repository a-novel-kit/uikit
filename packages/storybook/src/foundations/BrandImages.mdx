# Brand images

Import responsive banners and square application icons from `@a-novel-kit/uikit-images`.

## Banner

Use width descriptors and a `sizes` value that reflects the consuming layout. The browser can then
select the smallest source that covers the rendered slot and display density.

<figure className="brand-image-sample brand-image-sample--banner">
  <div className="brand-image-stage">
    <img
      alt="Agora"
      decoding="async"
      height="321"
      sizes="(max-width: 48rem) 100vw, 80rem"
      src={banner1280Url}
      srcSet={bannerSrcset}
      width="1280"
    />
  </div>
  <figcaption>
    <strong>Responsive banner</strong>
    <code>files/banner/{"{width}"}w/agora-banner.png</code>
  </figcaption>
</figure>

## Icon

Choose the file whose intrinsic square size matches the platform surface. Keep the image square and
let the platform apply its own mask.

<div className="brand-icon-grid">
  {iconSamples.map((sample) => (
    <figure className="brand-image-sample" key={sample.size}>
      <div className="brand-image-stage brand-image-stage--icon">
        <img
          alt=""
          height={sample.size}
          src={sample.url}
          style={{ "--brand-image-size": `${sample.size}px` }}
          width={sample.size}
        />
      </div>
      <figcaption>
        <strong>{sample.label}</strong>
        <code>{sample.size + "×" + sample.size}</code>
      </figcaption>
    </figure>
  ))}
</div>

The icon previews are decorative because their captions already identify each size. Product usage
needs meaningful alternative text unless adjacent content names Agora.
