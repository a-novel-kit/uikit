export const scale = (family) =>
  Object.fromEntries(
    Array.from({ length: 12 }, (_, index) => {
      const step = index + 1;
      return [`${family}.${step}`, `var(--color-${family}-${step})`];
    })
  );

# Color system

The interface uses one complementary pair on a neutral field. Electric blue carries agency and
progress. Its warm copper complement carries narrative pressure, caution, and failure.

Pressure derives from the brand hue with `calc(h + 180)`. Both families share the same base chroma
and calculated scale, so changing the blue keeps the pair balanced.

Feedback never depends on hue alone. Labels and icons carry meaning; surface, border, and text steps
increase emphasis inside the two-family grammar.

## Primitive scales

Steps move from the darkest surface value at `1` to the lightest text value at `12`. Chroma peaks
near the solid-control range.

## Authoring rule

Components use semantic color tokens and shared metric tokens. Verify every foreground/background
pairing with the accessibility panel; a visual palette step does not guarantee sufficient contrast.
