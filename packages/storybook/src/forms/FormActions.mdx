# Form actions

Groups submit controls and form-level feedback, with extra space after fields. Actions fill the
available width below 35rem; on larger viewports they use their natural width and wrap when needed.

## Usage

Import `FormActions` alongside the form controls from `@a-novel-kit/uikit`. Put fields and actions
in a `Stack` with `gap="4"`. Omit `feedback` when there is no form-level message. Field-specific
errors stay with their `Field`.

```svelte
<form method="POST">
  <Stack gap="4">
    <Field label="Display name">
      {#snippet children(control)}<Input {...control} name="displayName" />{/snippet}
    </Field>
    <FormActions>
      <Button type="submit">Save changes</Button>
    </FormActions>
  </Stack>
</form>
```

`FormActions` adds no form or live-region semantics. The caller owns submission, pending state,
and feedback announcements through components such as `Alert`. It adds no leading space when it
is the first element in its parent, which also supports action-only forms.
