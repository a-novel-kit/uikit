## Usage

```svelte
<script lang="ts">
  import { Alert, InlineMessage } from "@a-novel-kit/uikit";
</script>

<InlineMessage tone="loading">Loading account</InlineMessage>

<Alert tone="error" title="Account unavailable">The service could not be reached.</Alert>
```

The same status graphic and neutral text hierarchy appear at every size. `Alert` supports an `icon`
snippet for domain-specific graphics and an `actions` snippet for recovery controls.
`StatusState` provides the centered page/dialog composition.

Messages announce updates once; their graphics are decorative. Use `role="presentation"` for static
content already announced by navigation. Keep loading messages outside the region marked `aria-busy`.
