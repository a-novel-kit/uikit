# Button

Buttons trigger an action in the current context. Use `Link` for navigation.

<Canvas of={ButtonStories.Playground} />
<Controls of={ButtonStories.Playground} />

## Variants

| Variant   | Use                                     |
| --------- | --------------------------------------- |
| `solid`   | Primary action in a region.             |
| `outline` | Secondary action with a visible border. |
| `ghost`   | Quiet, supplementary, or cancel action. |

<Canvas of={ButtonStories.Variants} />

## Tones

Tone sets semantic intent. Use `brand` by default, `neutral` for utility actions, and `danger` for
destructive actions. `signal` communicates status and feedback, so it is not a button tone.

<Canvas of={ButtonStories.Tones} />

## Content

The default snippet accepts text, HTML, and Svelte components. Combine an icon with a visible label;
use `IconButton` for icon-only actions.

<Canvas of={ButtonStories.IconAndText} />

## Sizes

Use `md` by default, `sm` in compact controls, and `lg` in spacious layouts.

<Canvas of={ButtonStories.Sizes} />

## States

`aria-pressed="true"` creates a persistent brand or neutral toggle. Neutral toggles remain neutral
when selected. Danger buttons trigger destructive actions and do not represent selection. Selected
buttons remain unchanged on hover and active interaction. Use the native `disabled` attribute when an
action is unavailable.

<Canvas of={ButtonStories.States} />

## Accessibility

`Button` renders a native `<button>`, defaults to `type="button"`, and forwards native attributes and
event handlers. Provide a concise visible label or an accessible name.
