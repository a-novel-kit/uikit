# Button

Buttons trigger an action in the current context. Supply `href` for navigation with the same
appearance, or use `Link` for an inline text link.

<Controls of={ButtonStories.Playground} />

## Navigation

`href` renders a native anchor, including without JavaScript. It accepts anchor attributes such as
`target` and `rel`; form and disabled attributes belong to button actions. `IconButton` also accepts
`href` and always requires an accessible `label`.

<Canvas of={ButtonStories.NavigationLinks} />

## Variants

| Variant   | Use                                                 |
| --------- | --------------------------------------------------- |
| `solid`   | Primary action in a region.                         |
| `outline` | Secondary action with a visible border.             |
| `ghost`   | Quiet or supplementary action.                      |
| `text`    | Quiet secondary journey, or a cancel beside a form. |

<Canvas of={ButtonStories.Variants} />
<Canvas of={ButtonStories.ChosenByVariant} />

Outline and ghost buttons share translucent hover and active layers tinted with their text color.
A pressed outline button keeps its tone and border. A pressed ghost or text button reads as the navigation's
current item, blue whatever its tone, with no border or glow but its indicator's, as NavList's. Solid buttons keep a
filled surface.

## Tones

Tone sets semantic intent. Use `brand` by default, `neutral` for utility actions, and `danger` for
destructive actions. `signal` communicates status and feedback, so it is not a button tone.

<Canvas of={ButtonStories.Tones} />

## Content

The default snippet accepts text, HTML, and Svelte components. Combine an icon with a visible label;
use `IconButton` for icon-only actions.

<Canvas of={ButtonStories.IconAndText} />

## Sizes

Use `md` by default, `sm` in compact controls, and `lg` in spacious layouts.

<Canvas of={ButtonStories.Sizes} />

## States

`aria-pressed="true"` creates a persistent brand or neutral toggle. A solid or outline toggle keeps its tone when
selected; a ghost or text toggle turns blue, as the navigation's current item. Danger buttons trigger destructive
actions and do not represent selection. Selected buttons remain unchanged on hover and active interaction. Use the
native `disabled` attribute when an action is unavailable.

<Canvas of={ButtonStories.States} />

## Accessibility

`Button` renders a native `<button>`, defaults to `type="button"`, and forwards native attributes and
event handlers. Provide a concise visible label or an accessible name.
