# Component catalog

Components are grouped by their role in an interface.

| Area                                                                  | Components                                                                                                                                |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| [Actions](?path=/docs/components-button--documentation)               | `Button`, `IconButton`, `ButtonGroup`, `Link`, `ToggleButton`, `ToggleGroup`, `Toolbar`, `ActionMenu`                                     |
| [Layout](?path=/docs/layout-primitives--documentation)                | `Stack`, `Inline`, `Grid`, `Container`, `Card`, `PageHeader`, `SplitPane`, `AppShell`                                                     |
| [Forms](?path=/docs/forms-controls--documentation)                    | `Field`, `Fieldset`, `Input`, `Textarea`, `Select`, `Combobox`, `FileInput`, `Checkbox`, `RadioGroup`, `Switch`, `Slider`, `ErrorSummary` |
| [Navigation](?path=/docs/navigation-patterns--documentation)          | `NavList`, `Breadcrumbs`, `Pagination`, `Tabs`, `SkipLink`                                                                                |
| [Data display](?path=/docs/data-display-content--documentation)       | `Avatar`, `Badge`, `Table`, `DescriptionList`, `Prose`, `Separator`                                                                       |
| [Feedback](?path=/docs/feedback-status--documentation)                | `Alert`, `InlineMessage`, `Progress`, `Meter`, `Spinner`, `Skeleton`, `EmptyState`, `ToastRegion`                                         |
| [Overlays](?path=/docs/overlays-disclosure-and-dialog--documentation) | `Accordion`, `Disclosure`, `Popover`, `Dialog`, `Tooltip`                                                                                 |
| [Icons](?path=/docs/icons-catalog--documentation)                     | Named SVG components and `IconBase`                                                                                                       |
| Utility                                                               | `VisuallyHidden`                                                                                                                          |

## Import

Import components from `@a-novel-kit/uikit` and icons from `@a-novel-kit/uikit-icons`. The
[application shell](?path=/docs/recipes-application-shell--documentation) shows the packages composed
into a page layout.
