# Typography

Import `@a-novel-kit/uikit-fonts/fonts.css` once, then use the family and size tokens.

## Text styles

Text takes a style, never a size. One declaration sets the weight, size, line height and family of a role:

```css
.title {
  font: var(--text-title);
}
```

Pick the row that says what the text is. A component or an application never sets `font-size`, `line-height`
or `font-family`; `font: inherit` on a native control stays, and `font-weight` alone, with a weight token,
marks a state such as a chosen item. The page's root takes `--text-body`, so text with no style of its own
reads as content.

<div className="type-scale" aria-label="Text styles">
  {styles.map((style) => (
    <div key={style.token}>
      <code>{style.token}</code>
      <span style={{ font: "var(" + style.token + ")" }}>{style.sample}</span>
      <small>{style.use}</small>
    </div>
  ))}
</div>

A heading's level sets its style: level 2 takes `--text-title`, level 3 `--text-title-sm`, level 4
`--text-title-xs`. A `Section` finds its level from the sections that hold it.

## Color follows the role

| The text is                                                                          | Token                         |
| ------------------------------------------------------------------------------------ | ----------------------------- |
| What the reader came for: a title, content, a value, the label of a choice they make | `--color-text-primary`        |
| What names or explains it: a field's label, a description, a message's body          | `--color-text-secondary`      |
| What a reader can skip: a hint, a timestamp, a count, a link of the rail at rest     | `--color-text-muted`          |
| A placeholder, inside a well only: it fails 4.5:1 on an island                       | `--color-control-placeholder` |
| Disabled                                                                             | `--color-text-disabled`       |

## The scale under the styles

The styles draw from seven sizes, `--font-size-{xs,sm,md,lg,xl,2xl,4xl}`: 13, 14, 16, 18, 20, 23 and 29 pixels,
each a step of the density ratio rounded to a whole pixel. Line heights are 1, 1.25, 1.5 or 1.75 times their
size, rounded to an even pixel count, so stacked lines and a line centered in a control land on whole pixels.
TeX Gyre Heros ships 400 and 700 alone: the interface's medium comes from Arimo's weight axis, under the same
family name. The display face has no medium.
