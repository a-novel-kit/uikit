# Layout & shape

Use public spacing, radius, control, border, focus, and motion tokens in component styles.

## Spacing

The spacing scale starts at `--space-base`, 3 pixels. Each step sets one relationship: pick the
relationship, never the pixels. A component that owns a relationship already sets it: `Field`,
`Section`, `Stack`, `ActionGroup`, `FormActions`, `Card`.

| The space separates                                                                                                              | Token             | Size        |
| -------------------------------------------------------------------------------------------------------------------------------- | ----------------- | ----------- |
| Links of one navigation group                                                                                                    | none              | 0           |
| Lines of one item, such as a name and its details; a list's edge and its options                                                 | `--space-1`       | 3 px        |
| Chips or tags side by side, nothing else                                                                                         | `--space-1-5`     | 5 px        |
| Parts of one thing: an icon and its label, a label and its field, a field and its note, a title and its description              | `--space-2`       | 6 px        |
| Things that work as one unit: buttons in a group, a mark and its text block, islands side by side; a control's edge and its text | `--space-3`       | 9 px        |
| Siblings: fields, list rows, a heading and its content; a compact island's edge and its content                                  | `--space-4`       | 12 px       |
| A card's or a dialog's edge and its content, a dialog's parts, a page's top                                                      | `--space-6`       | 18 px       |
| Groups: sections of a page, a form's actions under its last field, a rail's top and bottom groups                                | `--space-8`       | 24 px       |
| A page's foot                                                                                                                    | `--space-12`      | 36 px       |
| A page's sides                                                                                                                   | `--layout-gutter` | 12 to 24 px |

Sizes keep a 4-pixel grid on the `--size-{N}` steps: control heights, icons, badges, marks, and the reach of
shadows and glows. A size never takes a `--space-*` token, and a space never takes a size.

A value no row holds is an exception. It carries an `/* off-scale: <reason> */` comment directly above
its declaration, and the token contract check lists every one:

```sh
uikit-token-contract --list-exceptions src
```

The check also fails on a token nothing defines, on a property that reads outside its family, and on a raw
length, duration or color where a scale exists. Run it in an application's lint.

<div className="metric-stack">
  {spacingTokens.map((token) => (
    <div className="metric-row" key={token}>
      <code>{token}</code>
      <div className="metric-track">
        <span className="spacing-swatch" style={{ "--metric-size": `var(${token})` }} />
      </div>
    </div>
  ))}
</div>

## Layout

Widths come from the layout tokens, never from a hand-picked size.

| Token                             | Use                                                                           | Size               |
| --------------------------------- | ----------------------------------------------------------------------------- | ------------------ |
| `--layout-container-xs`           | Compact dialogs, `Dialog size="sm"`                                           | 26.67 rem          |
| `--layout-container-sm`           | Forms, settings pages and dialogs, `Container size="sm"`                      | 40 rem             |
| `--layout-container-md`           | Wider pages, `Container size="md"`                                            | 64 rem             |
| `--layout-container-lg`           | Full application pages, `Container`'s default                                 | 80 rem             |
| `--layout-readable-measure`       | Running text, `Container size="readable"` and `Prose`                         | 68 ch              |
| `--layout-readable-measure-long`  | A short block in a card, such as a project's premise                          | 80 ch              |
| `--layout-sidebar`                | A navigation rail or a split pane's side                                      | 15.28 rem          |
| `--layout-floating-{sm,md,lg,xl}` | A floating surface: a menu's least width, a tooltip's most, a toast, a banner | 12, 16, 20, 32 rem |

Every page fills the viewport's height with `100dvb`, and the root keeps `min-inline-size: 20rem`:
WCAG 1.4.10 reflows content down to 320 CSS pixels, and a narrower window scrolls instead.

A viewport breakpoint is one of two widths, which a media query cannot read from a token: 35rem, where an
action group stops stacking, and 48rem, where a page stops being a phone's. A container query follows its
own content.

## Surfaces

Group related content with spacing first. Use a borderless island when a region needs its own visual
plane. `--shadow-{md,lg}` give an island a hairline ring and a soft shadow; its face stays flat.
`--shadow-floating` reaches every side, for a surface that floats over other islands. A
well, such as a field, darkens the surface it sits on, so it keeps that surface's tone. A field inside an
island, such as a card, a dialog or a fieldset, needs no border: only focus and errors outline it. A field
outside one, on the canvas or a sticky bar, takes a ghost card's ring (`--color-field-border`), so it stays in
view. The [field surfaces](?path=/story/forms-controls--surfaces) story compares them.

## Border radius

Choose a named radius token for each component shape. Each step doubles the one below: 3, 6, 12 and 24
pixels. A surface that holds another shape keeps their corners concentric: its radius is the inner
shape's radius plus the space between them.

- A card nested in another sits half the parent's radius from its edge and takes the next step down, at any
  depth. The card's other content sits a spacing step further in.
- Labeled buttons, fields, message boxes and navigation links take `--radius-lg`. An icon-only button or
  navigation item keeps `--radius-md`, so its small square still reads as square.
- A list, a toolbar or a toggle group adds its `--space-1` padding to its items' radius.

<div className="radius-grid">
  {radiusTokens.map((token) => (
    <div className="radius-card" style={{ "--metric-radius": `var(${token})` }} key={token}>
      <code>{token}</code>
    </div>
  ))}
</div>

## Control and interaction metrics

| Contract       | Tokens                                                                                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Control height | `--control-height-{sm,md,lg}`, one step taller on touch                                                                                                     |
| Icon size      | `--icon-size-{sm,md,lg}`: 16, 20 and 24 pixels                                                                                                              |
| Nested control | `--control-height-nested`, inside a medium field                                                                                                            |
| Border         | `--border-width-thin`                                                                                                                                       |
| Focus          | `--focus-ring-{width,offset}` and `--color-focus-ring`                                                                                                      |
| Motion         | `--motion-state` for a control changing state, `--motion-surface` for a surface that enters, leaves or resizes, `--motion-mark` for a mark landing in place |
| Disabled state | `--opacity-disabled`                                                                                                                                        |

A control's size follows its place. Medium is the default and takes no prop: a field, and the actions of a
form, a dialog or a toolbar. Small is an action inside a row or beside a title, a tab or an option. Large is
a page's only action, on a page built around it. An icon is 16 pixels inside a control, beside interface text
or in a message's mark, 20 beside content, and 24 when it stands alone as the icon of a state.

The [Button](?path=/docs/components-button--documentation) stories show these tokens on an interactive
control.
