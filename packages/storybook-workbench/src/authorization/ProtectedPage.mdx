# Protected pages

A page that needs access shows it once access is allowed, and otherwise the state that stops it. uikit translates
every state's copy; the app supplies only where its links go.

## Protected page

`ProtectedPage` inherits the app's authorization decision, as `AuthorizationBoundary` does, and centers the state
in the page while the decision is pending, forbidden or unavailable. It shows nothing for an anonymous decision,
since the app sends that visitor to its sign-in. Its `when` prop restricts access further.

```svelte
<script lang="ts">
  import { ProtectedPage } from "@a-novel-kit/uikit";

  let { data } = $props();
</script>

<ProtectedPage homeHref="/" retryHref={data.path}>
  <h1>Your projects</h1>
</ProtectedPage>
```

## Error pages

Each state is also a component of its own, for an error page that maps a status to a state: `AccessForbiddenState`
for 403, `AccessUnavailableState` for 503, `PageNotFoundState` for 404 and `PageErrorState` for any other failure.
`AccessPendingState` completes the set. The page around them owns its height and centering.

```svelte
<script lang="ts">
  import { AccessForbiddenState, PageErrorState, PageNotFoundState } from "@a-novel-kit/uikit";

  let { status, homeHref }: { status: number; homeHref: string } = $props();
</script>

{#if status === 403}
  <AccessForbiddenState {homeHref} headingLevel={1} />
{:else if status === 404}
  <PageNotFoundState {homeHref} headingLevel={1} />
{:else}
  <PageErrorState {homeHref} headingLevel={1} />
{/if}
```

## Own copy

A string or a snippet replaces a state's `title` or `description`, and `actions` replaces its link. To reword a
state everywhere, an app sets the message in its own `uikit` messages instead, under `access`, such as
`access.forbidden.title`. `useMessages()` reads the same text, as a page title naming the state does.

## Accessibility

Each state is a `StatusState`: its heading names the state, a pending state is a `status` live region and the
others an `alert`. Every state but the pending one offers a way out. The toolbar's language switches the copy.
